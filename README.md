# RogueFus

> Fangame non officiel, sans aucun lien avec Ankama. Dofus est une marque d'Ankama Games.

**RogueFus** : un jeu de donjons au tour par tour dans l'univers de Dofus 1.29, pour Windows, avec **mort définitive**.

On crée un personnage (12 classes : Iop, Crâ et Eniripsa au départ, les autres se débloquent dans les donjons), on chasse pour gagner de l'expérience et des kamas, on s'équipe, puis on attaque les donjons salle par salle, seul ou à plusieurs. Les sorts s'apprennent et se montent comme dans Dofus. Si le personnage meurt, il rejoint le cimetière.

## Installation

Il faut ton propre **client Dofus 1.29** (le dossier qui contient `clips` et `data`) et un fichier **`game.sql`** 1.29. Ils ne sont pas fournis.

1. Télécharger **`RogueFus-<version>.zip`** dans **[Releases](../../releases)** et le décompresser où tu veux (pas dans Program Files).
2. Lancer **`RogueFus.exe`**. Au premier lancement, indiquer le dossier du client et le fichier `game.sql` : la préparation du jeu prend quelques minutes, puis se termine pendant que tu joues.
3. Jouer.

Tes personnages et tes options restent dans le dossier `RogueFus`. Les mises à jour se font depuis le jeu (écran titre, ou Options › Vérifier les mises à jour). Pour désinstaller, supprimer le dossier.

## Commandes en combat

- Clic sur une case : se déplacer (le chemin et le coût en PM s'affichent au survol)
- `1`-`9` ou clic sur une icône : sélectionner un sort, puis clic sur la cible ; clic droit / `Échap` pour annuler
- `Espace` / `Entrée` : fin du tour (60 s par tour, pas réglable)
- Clic sur un combattant (sans sort choisi) ou sur sa ligne dans la file : épingler sa fiche (buffs, poisons, états)
- `Alt` + clic (ou le bouton ▼ sous le portrait) : montrer une case à l'équipe
- Flèche ⏏ en bas à droite : menu du personnage (caractéristiques, sorts, équipement), modifiable pendant le placement seulement
- `Échap` (ou Start à la manette) sans rien à annuler : Options (son, musique, ambiance, raccourcis, retour à l'écran titre, quitter)
- `M` : couper / remettre la musique
- Abandonner : une chance sur deux pour chaque personnage de perdre tout l'équipement porté, sinon il meurt
